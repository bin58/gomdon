# 📦 GomĐơn — Biến tin nhắn Zalo/Facebook thành bảng Excel dễ dàng

Ứng dụng web giúp chủ shop online, quán ăn, shop quần áo dán tin nhắn đặt hàng và tách tự động thành bảng **Khách hàng – SĐT – Địa chỉ – Món/Sản phẩm – Số lượng – Tiền thu – Ghi chú**.

**Hoạt động 100% miễn phí trên trình duyệt, không cần API Key, không lưu dữ liệu khách hàng lên mạng.**

---

## Tính năng nổi bật

- **Quy trình 3 bước đơn giản:** Dán tin nhắn → Kiểm tra & sửa trực tiếp trên bảng → Xuất Excel hoặc copy gửi Shipper.
- **Tách thông minh tin nhắn tiếng Việt:** Hỗ trợ cả đơn 1 dòng lộn xộn lẫn đơn nhiều dòng kiểu form Zalo, tự phân biệt tiền cọc với tổng tiền, tránh nhầm số size với số lượng, cảnh báo đơn thiếu SĐT/địa chỉ.
- **Tiện ích thực tế cho chủ shop:**
  - 📊 Tải file **Excel (`.xlsx`)** chuẩn font tiếng Việt (có bản dự phòng CSV giữ nguyên số `0` đầu SĐT).
  - 🛵 **Copy gửi Shipper (Zalo)** định dạng sẵn đẹp mắt.
  - 📄 **Copy kết quả** toàn bảng hoặc **📋 Copy từng dòng** đơn lẻ.
  - 📋 **Copy dán Google Sheets** giữ nguyên từng cột.
  - 🌙 **Chế độ tối / sáng** dịu mắt khi chốt đơn buổi tối.

---

## 1. Cách mở chạy thử ngay

1. Mở thư mục `gom-don-excel`.
2. Nhấp đúp vào file **`index.html`** (biểu tượng Chrome/Edge).
3. Bấm **🍜 Thử mẫu quán ăn** (hoặc **👗 Thử mẫu shop áo quần**) → bấm **✨ Tách thành danh sách đơn**.
4. Chỉnh sửa trực tiếp nếu cần, sau đó bấm **📊 Tải file Excel (.xlsx)** hoặc các nút Copy.

---

## 2. Cách đưa lên mạng miễn phí (30 giây)

1. Vào trang **Netlify Drop**: https://app.netlify.com/drop
2. Kéo thả nguyên thư mục `gom-don-excel` vào khung trên trang web.
3. Nhận ngay đường link web miễn phí dùng được trên cả điện thoại lẫn máy tính.
